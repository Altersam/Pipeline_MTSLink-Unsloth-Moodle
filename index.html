Pipeline_MTSLink-Unsloth-Moodle

MTS Link → LFU → Unsloth → Moodle

Полный файловый и агентный конвейер: получить запись, расшифровку и материалы занятия, превратить их локальной моделью в полноценный Moodle-safe HTML, проверить и автоматически перейти к следующему уроку.

1. Что делает система

MTS Link→ LFU Online Hub→ Расшифровка / Запись / files→ MoodleWorker→ Unsloth Studio→ lesson.html→ QA / FIX→ Moodle
LFU
Забирает материалы MTS Link и формирует чистую папку урока.
MoodleWorker
Управляет очередью, контекстом, watchdog, файлами и восстановлением.
Unsloth
Понимает тему, пишет теорию, примеры, SVG, таблицы и Moodle HTML.
Moodle
Получает уже проверенный HTML-фрагмент без JavaScript.

2. Как должна выглядеть папка

MoodleWorker выбирает именно родительский каталог уроки. Внутри — только непосредственные папки уроков с числовыми префиксами.

output/
└── 2026-10-03/
    └── уроки/
        ├── 00_09_00_10А_Литература/
        │   ├── Расшифровка.txt
        │   ├── Запись.txt
        │   └── files/
        ├── 01_10_00_10А_Физика/
        │   ├── Расшифровка.txt
        │   ├── Запись.txt
        │   └── files/
        └── ...
Минимальный вход: Расшифровка.txt, Запись.txt и при наличии files/.

Расшифровка.txt

Главный источник предмета и фактической темы. Если файл отсутствует или пуст, worker не должен выдумывать урок.

Запись.txt

Реальная ссылка/ссылки записи MTS Link. Worker никогда не создаёт URL сам.

files/

Вложения преподавателя: DOCX, PPTX, XLSX, PDF, изображения, TXT, HTML и другие полезные материалы.

3. LFU Online Hub v2.6

LFU — upstream-часть. Начиная с v2.6 папка урока очищена от лишнего технического сырья.

Запись.txt
Одна/несколько ссылок. Основной источник — записи текущей EventSession.
Расшифровка.txt
Полный опубликованный transcript в формате «время — участник — текст».
files/
Оригинальные attachments EventSession/Event, без повторных дубликатов.

Технические JSON посещаемости могут храниться отдельно в посещаемость/_сырье, но не должны смешиваться с учебным пакетом.

Секреты LFU. Не публикуйте API.txt. Он может содержать MTS token, Eljur devkey и логины/пароли.

4. Настройка Unsloth Studio

Для рабочего LAN-примера текущая Studio доступна по адресу:

http://192.168.1.12:8888

На другой машине используйте её реальный IP/порт.

1
Запустите Studio.
unsloth studio -H 0.0.0.0 -p 8888
2
Проверьте страницу login.
http://IP:8888/login
3
Если пароль потерян:
unsloth studio reset-password
4
Для LAN: включите Settings → API keys → LAN access.

Как авторизуется MoodleWorker

POST /api/auth/login
{"username":"unsloth","password":"..."}

→ access_token

GET  /v1/models
POST /v1/chat/completions
Authorization: Bearer <access_token>

При 401 v0.5 автоматически получает новый JWT.

6. Почему worker не «забывает продолжить»

INGEST→ EXTRACT→ PLAN→ BUILD→ READ_BACK→ QA→ FIX→ COMMIT→ RESET→ NEXT

Модель не управляет циклом. Циклом управляет приложение.

EXTRACT
Сырая расшифровка → компактный lesson_context.json.
PLAN
Компактная память → lesson_plan.json.
BUILD
Новый API-запрос без полной старой истории → HTML.
QA/FIX
Новый запрос + локальный validator.

Следующий урок начинается отдельным набором сообщений. Поэтому длинная история 17–27 уроков не растёт бесконечно.

7. Что получается и что загружать в Moodle

В папке урока после успешного цикла:

lesson_context.json
lesson_plan.json
lesson.html
lesson_build_report.json

Если lesson.html уже был, создаётся улучшенная версия lesson_improved.html, затем lesson_improved_2.html и т.д.

В Moodle нужен именно HTML-фрагмент

Откройте нужный ресурс/страницу/описание в Moodle, переключитесь в HTML/source-режим редактора и вставьте содержимое готового HTML-файла. Конкретное название кнопки зависит от установленного редактора Moodle и прав пользователя.

Проверенный WAF-safe профиль

Разрешено
inline CSS, table, pre/code, details/summary, статический SVG, простой iframe записи.
Запрещено
script, javascript:, onclick/onload/onerror, srcdoc, object/embed, активный SVG, локальные пути.

8. Сборка из исходников

MoodleWorker написан на Go и не требует сторонних Go-модулей.

cd apps/MoodleWorker

set GOOS=windows
set GOARCH=amd64
set CGO_ENABLED=0

go build -trimpath -ldflags="-s -w -H=windowsgui" -o dist\MoodleWorker.exe .

Также доступны build_windows.bat, build_windows.ps1 и GitHub Actions.

GitHub Actions

  • build-windows.yml — build artifact;
  • release.yml — Release при теге moodleworker-v*;
  • pages.yml — публикация этой документации в GitHub Pages.

9. Типовые ошибки

HTTP 404 API endpoint not found

Проверьте OpenAI-compatible prefix /v1. В v0.5 проще оставить API Base URL пустым.

HTTP 401 Invalid or expired API key

Нажмите Починить подключение. Старый API key/JWT будет заменён входом через Studio password.

trycloudflare URL

Не используйте старый временный Quick Tunnel, если Studio доступна по LAN.

needs_review

Откройте lesson_build_report.json. После устранения причины используйте кнопку возврата failed/needs_review в очередь.

Контекст / RAM / VRAM

Worker уже разделяет урок на stateless stages. Поэтому нет необходимости держать один гигантский chat-context на весь день.

10. Безопасность

Никогда не публикуйте в GitHub: API.txt, MTS token, ЭлЖур credentials, Studio password, API keys/JWT, реальные student emails/eljurID, приватные записи и расшифровки.

Локальные настройки MoodleWorker лежат в %APPDATA%\MoodleWorker\settings.json. Этот файл не должен попадать в репозиторий.
