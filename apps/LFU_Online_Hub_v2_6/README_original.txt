LFU Online Hub v2.6
===================

Главное изменение: материалы MTS Link очищены и исправлены.

В папке output/<дата>/уроки/<урок>/ теперь создаются ТОЛЬКО:

1. Запись.txt
   - одна или несколько ссылок на запись, по одной ссылке на строку;
   - в первую очередь берётся нормальная ссылка онлайн-записи из GET /records,
     строго по EventSessionID текущего урока;
   - если обычная ссылка не найдена, используется downloadUrl из
     GET /eventsessions/{eventSessionId}/converted-records.

2. Расшифровка.txt
   - полная опубликованная текстовая расшифровка занятия;
   - формат: [время] Участник: текст;
   - поддерживается пагинация списка расшифровок;
   - исправлен endpoint: после получения transcriptId используется
     GET /transcript/{transcriptId};
   - старый вариант /eventsessions/{sid}/transcript/{id} больше не используется;
   - если для одной EventSession опубликовано несколько расшифровок, их текст
     объединяется, повторяющиеся фрагменты удаляются.

3. files/
   - создаётся только если к мероприятию действительно прикреплены файлы;
   - проверяются и файлы EventSession, и файлы серии Event;
   - учитывается реальная структура ответа MTS API: данные файла находятся
     во вложенном объекте file;
   - скачивается оригинальный файл через downloadUrl;
   - дубликаты не скачиваются повторно.

БОЛЬШЕ НЕ СОЗДАЮТСЯ в папке урока:
- converted_records.json
- records.json
- transcript_list.json
- transcript_*.json
- session_files.json
- event_files.json
- lesson.html
- lesson_info.txt

При повторном запуске за ту же дату папка материалов конкретного урока сначала
пересоздаётся, поэтому мусор от v2.5 и более ранних версий там не останется.

Важно
------
Технические JSON, необходимые для диагностики ПОСЕЩАЕМОСТИ, могут оставаться в
output/<дата>/посещаемость/_сырье. Это отдельный диагностический контур и он не
смешивается с материалами уроков.

Файлы урока теперь всегда скачиваются автоматически. Переключатель
«скачивать файлы» удалён из интерфейса.

Остальная логика v2.5 сохранена:
- единый API.txt с ЭлЖур + MTS_API;
- многоклассовые встречи разбиваются по классам;
- grp не используется как ориентир;
- запись Н: eljurID + lesson_id + дата + класс;
- read-before-write и read-after-write для ЭлЖура.

Сборка Windows x64
------------------
set GOOS=windows
set GOARCH=amd64
set CGO_ENABLED=0
go build -trimpath -ldflags="-s -w -H=windowsgui" -o LFU_Online_Hub_v2_6.exe .
