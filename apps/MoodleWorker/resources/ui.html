Рекомендуемые настройки для твоего Unsloth: Studio URL = http://192.168.1.12:8888, пользователь = unsloth. Заполни только пароль Studio. API Base URL, Model ID и API key лучше оставить пустыми. MoodleWorker сам войдёт через /api/auth/login, получит JWT, обновит его после HTTP 401 и возьмёт фактически загруженную модель через /v1/models.

Если остались старые Cloudflare URL/API key, нажми «Починить подключение»: они будут очищены, а локальный Studio будет использован напрямую.

Если пароль Studio забыт, на машине с Unsloth выполни: unsloth studio reset-password. Для Windows-установки из папки Studio также может работать: & .\unsloth_studio\Scripts\unsloth.exe studio reset-password.
Доп. инструкции
Skill и основной prompt уже встроены в EXE. Внешние файлы указывай только если хочешь заменить их.
