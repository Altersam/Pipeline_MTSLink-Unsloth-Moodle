# Troubleshooting

## Unsloth: offline + HTTP 404

Проверьте, что API идёт через `/v1`.

В v0.5 обычно достаточно оставить `API Base URL` пустым и указать только Studio URL.

## HTTP 401 Invalid or expired API key

1. Очистите старый API key.
2. Оставьте API Base URL пустым.
3. Введите Studio password.
4. Нажмите `Починить подключение`.

v0.5 автоматически обновляет JWT после `401`.

## trycloudflare URL

Не используйте сохранённый временный Cloudflare quick-tunnel для локальной машины, если доступен LAN URL Studio.

## Урок завис на `in_progress`

Worker хранит статус на диске.

После перезапуска:

- сначала берётся первый `in_progress`;
- затем `queued`;
- `done` не перерабатываются.

## Урок попал в `needs_review`

Причины сохраняются в:

```text
lesson_build_report.json
moodle_batch_status.json
```

Кнопка `Вернуть failed/needs_review` возвращает такие уроки в очередь.

## Расшифровка не найдена

Проверьте точное имя:

```text
Расшифровка.txt
```

и кодировку UTF-8.

## Запись отсутствует

Урок может быть создан без видео. Worker не должен придумывать URL.

## PDF плохо читается

PDF extraction встроен как best-effort. Если PDF сканированный или со сложными шрифтами, конвертируйте материал в DOCX/TXT либо включите изображения/vision для подходящих материалов.

## Moodle блокирует HTML

Проверьте профиль `docs/MOODLE_SAFE_HTML.md`.

Особенно:

- script;
- event handlers;
- javascript:;
- srcdoc;
- foreignObject;
- локальные пути.

## YandexDisk тормозит

Worker специально:
- не сканирует весь диск;
- не использует бесконечный `find`;
- пишет HTML крупными операциями;
- сохраняет JSON через временный файл + replace.

Для стабильности не держите папку `уроки/` открытой большим числом внешних индексаторов/антивирусных операций во время массовой обработки.
