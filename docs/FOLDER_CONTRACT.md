# Контракт папки урока

MoodleWorker ожидает один родительский каталог `уроки/` и непосредственные папки внутри него.

## Обязательный файл

### `Расшифровка.txt`

Главный источник темы урока.

Пример:

```text
[00:00:05] Иванова Мария: Сегодня рассматриваем закон Ома...
[00:03:14] Ученик: А как изменится сила тока...
```

Если файл пуст или отсутствует, урок не может быть полноценно обработан.

## Запись

### `Запись.txt`

Одна или несколько реальных ссылок на запись.

LFU v2.6 кладёт ссылки по одной на строку.

Если файла нет, MoodleWorker продолжит, но не будет выдумывать URL.

## Дополнительные материалы

### `files/`

Опциональная папка.

Поддерживаются:

- TXT/MD/CSV/JSON;
- HTML (текст извлекается без script/style);
- DOCX;
- PPTX;
- XLSX/XLSM;
- PDF — best-effort;
- PNG/JPG/JPEG/WEBP при включённом Vision.

Не кладите в `files/` тысячи технических JSON MTS Link. Начиная с LFU v2.6 материалы урока очищены от технического сырья.

## Результат

После обработки внутри папки появятся:

```text
lesson_context.json
lesson_plan.json
lesson.html                # если ранее урока не было
lesson_improved.html       # если lesson.html уже существовал
lesson_improved_2.html     # следующие версии
lesson_build_report.json
```

`lesson_context.json` — компактная внешняя память.

`lesson_plan.json` — план структуры и визуализаций.

`lesson_build_report.json` — QA-результат.

## Состояние всего пакета

В корне `уроки/`:

```text
moodle_batch_status.json
moodle_pipeline_state.json
moodle_batch_summary.json
```

Эти файлы позволяют восстановиться после падения/перезапуска без повторной обработки `done`.
